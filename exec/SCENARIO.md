# 시연 시나리오

이 문서는 프로젝트의 주요 기능과 흐름을 효과적으로 보여주기 위한 시연 시나리오입니다.

## 1. 도입 및 로그인
**목표**: 사용자의 첫 진입부터 로그인까지의 부드러운 흐름을 보여줍니다.

### 1-1. 메인 (랜딩) 페이지 (`/`)
- **화면 설명**: 
    - "RoomInCode"의 정체성을 보여주는 세 가지의 게임 모드를 강조하고 있습니다.
- **시연 액션**:
    - 화면 중앙의 요소에 마우스 Hover하여 소개 내용을 훑어봅니다.
    - 우측 상단 또는 중앙의 **[로그인]** 버튼을 클릭합니다.

### 1-2. 로그인 페이지 (`/signin`)
- **화면 설명**: 
    - 깔끔한 로그인 폼과 소셜 로그인(GitHub 등) 옵션이 있습니다.
- **시연 액션**:
    - (선택) 회원가입 버튼을 눌러 회원가입 페이지(`signup`)로 이동했다가 다시 돌아옵니다.
    - **[소셜 로그인]** 버튼을 클릭하거나 회원가입한 계정으로 로그인합니다.
    - 로그인 성공 후 메인 대시보드로 리다이렉트됩니다.

---

## 2. 메인 대시보드 및 마이페이지
**목표**: 로그인 후 사용자 경험과 개인화된 정보를 보여줍니다.

### 2-1. 로그인 후 메인 페이지 (`/`)
- **화면 설명**: 
    - "게임 모드 선택" 카드가 중앙에 배치되어 있습니다 (AI 모드, 친구 대전, 랭킹전(컨테스트)).
    - 상단 네비게이션 바에 사용자 프로필 이미지가 표시됩니다.
- **시연 액션**:
    - 상단 프로필 우측에 있는 버튼을 클릭하여 **[마이페이지]**로 이동합니다.

### 2-2. 마이페이지 (`/mypage`)
- **화면 설명**: 
    - 사용자의 티어 정보, 최근 게임 기록 등이 그래프나 리스트로 시각화되어 있습니다.
- **시연 액션**:
    - "내 정보 수정" 버튼을 눌러 수정 페이지(`/mypage/edit`) 진입.
    - 닉네임이나 프로필 이미지를 변경하는 기능을 수행하고, 저장 또는 취소 후 돌아옵니다.
    - 다시 **[메인 로고]**를 클릭하여 대시보드로 복귀합니다.

---

## 3. 핵심 기능: AI 모드
**목표**: 이 프로젝트의 핵심인 AI와의 1:1 코딩 대결을 시연합니다.

### 3-1. AI 대결 설정 (`/ai`)
- **화면 설명**: 
    - 난이도(EASY, MEDIUM, MEDIUM_HARD, HARD, VERY_HARD), 언어(Python, Java, C++), 알고리즘 유형을 선택하는 폼.
- **시연 액션**:
    - 난이도: `Normal`, 언어: `Python`, 알고리즘: `DP` 등으로 설정.
    - **[게임 시작]** 버튼 클릭 -> 매칭 로딩 화면 후 게임 화면으로 이동.

### 3-2. AI 대결 게임룸 (`/ai/:matchId`)
- **화면 설명**: 
    - **좌측**: 알고리즘 문제 설명.
    - **중앙**: Monaco Editor (코드 작성 구역).
    - **우측**: 메모장, 피드백 영역.
    - **상단**: 남은 시간 타이머, 턴 진행 상태(내 턴/AI 턴).
- **시연 액션 (주요 포인트)**:
    1.  **설계 단계 (Design Phase)**:
        - 메모장에 문제 풀이 전략을 적습니다.
        - "설계 완료" 버튼 클릭.
    2.  **내 턴 (My Turn)**:
        - 에디터에 코드를 일부 작성합니다. (`def solution...`)
        - 시간이 다 되어 턴이 넘어가는 것을 보여줍니다.
    3.  **AI 턴 (AI Turn)**:
        - AI가 코드를 작성하는 모습이 끊김 없이 부드럽게 이어지는 효과로 나타납니다.
    4.  **제출 및 채점**:
        - 코드가 완성되면 **[제출]** 버튼 클릭.
        - 채점 결과(성공/실패) 확인.

### 3-3. 게임 결과 및 리포트 (`/ai/report/:matchId`)
- **화면 설명**: 
    - 게임 승패 결과.
    - AI의 코드 분석 리포트 (코드 품질, 효율성, 개선점 등).
- **시연 액션**:
    - 리포트 내용을 스크롤하며 AI가 분석해준 피드백을 확인합니다.
    - "메인으로 돌아가기" 클릭.

---

## 4. 확장 기능: 친구 대전
**목표**: 실시간 멀티플레이어 경험을 보여줍니다.

### 4-1. 친구 대전 로비 (`/friends/lobby`)
- **화면 설명**: 
    - 접속 중인 친구 목록, 방 만들기 버튼.
- **시연 액션**:
    - **[방 만들기]** 클릭 -> 친구에게 비밀번호 공유 후 즐기는 시나리오.

### 4-2. 친구 대전 게임룸 (`/friends/:matchId`)
- **화면 설명**: 
    - AI 모드와 유사하지만, 상대방 화면(또는 화상/음성)이 보이거나 이모지 반응 기능이 활성화됨.
- **시연 액션**:
    - 채팅 대신 **[이모지]**를 날려 소통하는 모습 (보글보글 올라가는 이모지 효과).
    - 실시간으로 서로 코드를 작성하며 턴을 주고받는 긴장감 연출.

---

## 5. 컨테스트 (Contest Mode)
**목표**: 다수의 사용자가(4인) 참여하는 경쟁 모드입니다.

### 5-1. 컨테스트 대기 및 진행
- **화면**: 리더보드(`/contest/leaderboard`) 또는 투표 화면(`/contest/vote/:matchId`).
- **시연 액션**:
    - 실시간으로 변동되는 랭킹 보드 확인.
    - 원하는 알고리즘 유형을 투표하는 기능.

---

## 6. 마무리 (Closing)
- **액션**: 다시 메인 페이지로 돌아와서 깔끔하게 로그아웃.
